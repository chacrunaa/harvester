# history

Архив завершённых прогонов. Заполняется автоматически после завершения pipeline.

```
history/
├── pipelines/   — полный лог выполнения pipeline (хронология всех шагов)
├── chats/       — архивные копии диалогов по датам
├── reports/     — итоговые отчёты по задачам
├── diffs/       — зафиксированные расхождения между фазами
└── briefs/      — архив всех брифов задачи
```
