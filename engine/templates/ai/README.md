# ai-skeleton

Пустая структура `.ai/` для нового проекта. Копируется скриптом `init-project.sh` / `init-project.ps1`.

```
ai-skeleton/
├── pipeline-state.json       — машина состояний (task_id и created_at заполняет скрипт)
├── backlog/                  — очередь задач проекта
├── chats/                    — рабочие директории агентов
└── history/                  — архив завершённых прогонов
```
