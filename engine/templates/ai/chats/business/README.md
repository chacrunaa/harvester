# chats/business

Фаза бизнес-анализа. Пять агентов работают параллельно после старта product-manager.

```
business/
├── cross-brief.md          — единый бриф для всех аналитиков (пишет product-manager)
├── brief-business.md       — финальный синтез (пишет product-manager)
├── diff.md                 — расхождения между отчётами аналитиков
├── chat.json               — история диалогов этой фазы
├── product-manager/        — оркестратор + сводные отчёты
├── product-analyst/        — бриф продукта + БФТ
├── market-analyst/         — ЦА + конкуренты + рынок + инсайты
├── strategist/             — бизнес-модель + УТП + метрики
└── financier/              — юнит-экономика + финмодель + MVP + CustDev
```
