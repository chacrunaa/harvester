# chats/business/product-manager/reports

Сюда Harvester автоматически копирует отчёты аналитиков после их завершения.

| Файл | Источник |
|---|---|
| `product-analyst.md` | `business/product-analyst/report.md` |
| `market-analyst.md` | `business/market-analyst/report.md` |
| `strategist.md` | `business/strategist/report.md` |
| `financier.md` | `business/financier/report.md` |

Файлы появляются по мере завершения агентов — не одновременно.
product-manager запускается когда все четыре файла присутствуют (AND-gate).
