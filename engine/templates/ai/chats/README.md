# chats

Рабочие директории агентов. Каждая фаза — своя поддиректория.

```
chats/
├── office-manager/   — инициализация, мониторинг, завершение
├── business/         — бизнес-анализ (5 агентов)
├── systemic/         — системный анализ (3 агента)
├── development/      — разработка (4 агента)
├── testing/          — тестирование (3 агента)
└── dialogs/          — история диалогов с пользователем (qna)
```

Агент пишет только в свою директорию. Harvester маршрутизирует файлы между агентами.
