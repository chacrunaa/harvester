# chats/testing

Фаза тестирования. QA и penetration работают параллельно.

```
testing/
├── brief-business.md    — бизнес-бриф (копирует Harvester)
├── brief-systemic.md    — системный бриф (копирует Harvester)
├── brief-development.md — бриф разработки (копирует Harvester)
├── brief-testing.md     — итоговый статус тестирования (пишет qa-lead)
├── diff.md              — расхождения между отчётами
├── chat.json            — история диалогов фазы
├── qa-lead/             — оркестратор + сводные результаты
├── qa/                  — функциональное тестирование
└── penetration/         — penetration testing
```
