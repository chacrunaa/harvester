# chats/development

Фаза разработки. Backend и frontend работают параллельно, затем reviewers.

```
development/
├── brief-systemic.md    — системный бриф (копирует Harvester)
├── brief-development.md — итоговый бриф разработки (пишет dev-lead)
├── diff.md              — расхождения между результатами
├── chat.json            — история диалогов фазы
├── dev-lead/            — оркестратор + результаты + review-цикл
├── backend/             — серверная разработка
├── frontend/            — клиентская разработка
└── reviewers/           — code review
```
