# chats/office-manager

Директория office-manager. Три сценария: инициализация, мониторинг, завершение.

| Файл | Когда появляется | Назначение |
|---|---|---|
| `start.md` | init | описание задачи от пользователя |
| `experience.md` | всегда | накопленный опыт агента |
| `incidents.md` | при сбоях | лог failed агентов и инцидентов |
| `finish.md` | завершение | итоговый статус pipeline |
