# chats/systemic/owner

Оркестратор системной фазы. Управляет очередью задач для analyst.

| Файл / Директория | Назначение |
|---|---|
| `experience.md` | накопленный опыт агента |
| `task-queue.md` | список задач для analyst в порядке выполнения |
| `current-task.md` | текущая задача (перезаписывается при каждой диспетчеризации) |
| `results/` | ответы analyst на каждую задачу |
| `spec.md` | финальная системная спецификация |
| `tech-proposal.md` | тех-предложение для architect |
| `recommendation.md` | итоговый executive summary для product-manager |
