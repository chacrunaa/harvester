# Инструкция 09 — Метрики продукта

## Роль AI-агента

> Ты продуктовый аналитик с опытом построения систем метрик. Твоя задача — определить иерархию метрик от North Star до операционных KPI, объяснить связи между ними и задать реалистичные целевые значения. Используй data-informed подход: данные + экспертное суждение.

## Теоретическая база (из курса «Экономика продукта», модуль «Метрики»)

**Определение:** Метрика — количественная характеристика, по которой можно сделать вывод об успешности продукта, проекта или действия.

**5 критериев хорошей метрики (по курсу):**
1. **Сравнимая** — есть с чем сравнить (другой период, бенчмарк отрасли)
2. **Понятная** — можно объяснить любому члену команды
3. **Коррелирующая с целями** — связана со стратегическими целями компании
4. **Подвластная** — команда может на неё влиять
5. **Доступная для расчёта** — технически можно замерить

**Типы метрик по курсу:**
- **Бизнес-метрики** (ARPPU, EBITDA, MRR) — состояние бизнеса в деньгах
- **Маркетинговые метрики** (CTR, CAC, CR) — эффективность привлечения
- **Продуктовые метрики** (DAU, MAU, NPS, RR) — вовлечённость и ценность для пользователя

**Data-driven vs Data-informed (по курсу):**
- **Data-driven** — решения принимаются только на основе данных (риск: игнорирование контекста)
- **Data-informed** — данные + экспертное мнение + стратегический контекст (рекомендуется)

## Задача

### 1. North Star Metric (NSM)

**Определение:** Одна метрика, которая лучше всего отражает ценность, которую продукт создаёт для пользователей, и при этом предсказывает долгосрочный рост бизнеса.

**Правила хорошего NSM:**
- Отражает ценность для пользователя, а не для бизнеса (не выручка сама по себе)
- Ведёт к росту выручки опосредованно
- Команда может на неё влиять
- Измеряется регулярно

**Примеры NSM по типам продуктов:**

| Тип продукта | North Star Metric |
|---|---|
| EdTech (курсы) | Количество завершённых уроков в неделю / Completion Rate |
| Социальная сеть | DAU, количество сообщений в день |
| E-commerce | Количество успешных покупок в месяц |
| SaaS B2B | Количество активных рабочих мест |
| Маркетплейс | Количество успешных транзакций |
| Стриминг | Часы просмотра контента |

**Кандидаты на NSM для данного продукта:**

### 2. Пирамида метрик

По курсу, пирамида строится снизу вверх — от технических до бизнесовых:

```
        ┌─────────────────────────────┐
        │     БИЗНЕСОВЫЕ МЕТРИКИ      │  ← MRR, LTV, ROI
        │  (эффективность бизнеса)    │
        └───────────┬─────────────────┘
                    │
        ┌───────────▼─────────────────┐
        │     ПРОДУКТОВЫЕ МЕТРИКИ     │  ← NSM, Retention, NPS
        │   (ценность для юзеров)     │
        └───────────┬─────────────────┘
                    │
        ┌───────────▼─────────────────┐
        │   ИНТЕРФЕЙСНЫЕ МЕТРИКИ      │  ← Conversion, DAU, Sessions
        │   (взаимодействие с UI)     │
        └───────────┬─────────────────┘
                    │
        ┌───────────▼─────────────────┐
        │   ПЛАТФОРМЕННЫЕ МЕТРИКИ     │  ← Uptime, Load time, Error rate
        │   (работоспособность)       │
        └─────────────────────────────┘
```

### 3. Дерево метрик (иерархия)

В отличие от пирамиды, дерево показывает причинно-следственные связи:

```
NSM: [Название]
│
├── Acquisition (привлечение)
│   ├── Новые регистрации/мес
│   ├── CAC по каналам
│   └── Organic / Paid split
│
├── Activation (активация)
│   ├── Onboarding completion rate
│   ├── Time to first value (до первого "aha moment")
│   └── Activation rate (D7)
│
├── Revenue (монетизация)
│   ├── Конверсия free → paid
│   ├── ARPU / ARPPU
│   └── MRR
│
├── Retention (удержание)
│   ├── Retention D1 / D7 / D30
│   ├── Churn Rate (monthly)
│   ├── DAU/MAU (Sticky Factor)
│   └── LTV
│
└── Referral (рекомендации)
    ├── NPS
    └── Viral Coefficient (K-factor)
```

Для каждого узла дерева укажи:
- Текущее значение
- Целевое значение (12 мес)
- Инструмент замера

### 4. HEART-метрики

Фреймворк Google для оценки UX-качества продукта:

| Измерение | Что означает | Метрика | Цель | Инструмент |
|---|---|---|---|---|
| **H**appiness | Насколько пользователи довольны | NPS, CSAT, Rating в сторах | NPS ≥ 70 | Опрос in-app |
| **E**ngagement | Насколько активно используют | Сессий/нед, Время в приложении, DAU/MAU | DAU/MAU ≥ 30% | Amplitude |
| **A**doption | Насколько принята новая функция | % активировавших функцию за 14 дней | ≥ 40% | Яндекс Метрика |
| **R**etention | Удерживает ли продукт | Retention D30, Churn | Churn ≤ 10%/мес | Когортный анализ |
| **T**ask Success | Достигают ли пользователи цели | Completion Rate, Error Rate | CR ≥ 70% | Product Analytics |

### 5. AARRR-воронка (пиратские метрики)

Фреймворк Dave McClure для полного цикла пользователя:

| Этап | Что измеряем | Метрика | Текущее | Цель (12 мес) | Инструмент |
|---|---|---|---|---|---|
| **A**cquisition | Откуда приходят | Новые пользователи/мес, CAC, CTR | … | … | Яндекс Метрика, GA4 |
| **A**ctivation | Получили ли ценность | Activation Rate (первый «aha moment»), D1 Retention | …% | …% | Amplitude |
| **R**evenue | Платят ли | Конверсия free→paid, ARPU, MRR | …% | …% | CRM |
| **R**etention | Возвращаются ли | Retention D7/D30, Churn Rate | …% | …% | Когортный анализ |
| **R**eferral | Рекомендуют ли | NPS, Referral Rate, Viral Coefficient | … | … | Опрос, AppMetrica |

**Sticky Factor = DAU / MAU** — один из ключевых показателей «прилипчивости»:
- Социальные сети: 50–70%
- Утилиты: 25–35%
- EdTech: 15–25%
- E-commerce: 5–15%

### 6. Ключевые формулы (по курсу)

```
DAU = Количество уникальных пользователей, активных за день
MAU = Количество уникальных пользователей, активных за месяц
Sticky Factor = DAU / MAU

Retention Rate D1 = (Пользователи, вернувшиеся на D1) / (Новые пользователи в D0)
Retention Rate D30 = (Пользователи, вернувшиеся на D30) / (Новые в D0)

Churn Rate (monthly) = 1 − Monthly Retention Rate
NPS = % Promoters − % Detractors
      (Promoters: оценка 9–10; Detractors: 0–6)

Viral Coefficient (K) = Количество приглашений × Конверсия приглашения
  K > 1 → вирусный рост; K < 1 → нет вирусности
```

### 7. Метрики тщеславия vs Метрики эффективности

**Метрики тщеславия** (vanity metrics) — выглядят красиво, но не отражают здоровье бизнеса:
- Суммарное количество регистраций (без Retention)
- Количество установок (без Activation)
- Количество просмотров страницы (без вовлечённости)
- Количество подписчиков в соцсетях

**Метрики эффективности** (actionable metrics) — показывают реальное состояние:
- DAU / WAU / MAU с динамикой
- Retention D1, D7, D30
- Conversion Rate free → paid
- LTV/CAC Ratio
- NPS с динамикой

## Критерии качества

- [ ] NSM выбрана с обоснованием по критериям (ценность + предсказывает рост)
- [ ] Пирамида и дерево метрик построены для конкретного продукта
- [ ] HEART и AARRR заполнены с конкретными числами
- [ ] Метрики тщеславия явно перечислены и исключены из KPI
- [ ] Все метрики имеют инструмент замера
- [ ] Целевые значения реалистичны (не >5x от стартовых за первый год)
- [ ] Sticky Factor рассчитан и сравнён с бенчмарком отрасли
