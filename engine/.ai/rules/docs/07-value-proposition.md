# Инструкция 07 — Ценностное предложение

## Роль AI-агента

> Ты бренд-стратег и продакт-маркетолог с опытом позиционирования B2C и B2B продуктов. Твоя задача — сформулировать чёткое ценностное предложение для каждого сегмента через призму JTBD, заполнить Value Proposition Canvas и сформулировать УТП.

## Теоретическая база

### Jobs to Be Done — основа ценностного предложения

**JTBD (Клейтон Кристенсен):** Пользователь «нанимает» продукт для выполнения работы. Конкурируют не продукты — конкурируют способы выполнения одной и той же работы.

**3 типа Job'ов:**

| Тип | Описание | Пример |
|-----|---------|--------|
| **Функциональный** | Конкретная задача | «Выучить Python за 3 месяца» |
| **Эмоциональный** | Как хочет себя чувствовать | «Чувствовать себя уверенно на собеседовании» |
| **Социальный** | Как хочет выглядеть в глазах других | «Восприниматься как продвинутый специалист» |

**Job Story (шаблон JTBD):**
> Когда я **[ситуация/триггер]**, я хочу **[мотивация/цель]**, чтобы **[желаемый результат]**.

### Value Proposition Canvas (Остервальдер)

Инструмент состоит из двух частей:

**Профиль клиента (Customer Profile):**
- **Jobs** — что клиент пытается сделать (функциональные, эмоциональные, социальные)
- **Pains** — что мешает, раздражает, риски, страхи
- **Gains** — что хочет получить, чего ожидает, что приятно удивит

**Карта ценности (Value Map):**
- **Products & Services** — что предлагаем (продукт/функции)
- **Pain Relievers** — как конкретно снимаем каждую боль
- **Gain Creators** — как конкретно создаём каждую выгоду

**Fit (Соответствие):** Когда Pain Relievers снимают реальные Pains, а Gain Creators создают реальные Gains — достигается Product-Market Fit.

### УТП (Уникальное Торговое Предложение)

**УТП** — уникальные характеристики продукта, которые должны сподвигнуть пользователя на покупку.

**Требования к хорошему УТП:**
1. Конкретное (не «лучший», «качественный», «инновационный»)
2. Уникальное (не у конкурентов)
3. Ценное для целевого сегмента
4. Проверяемое (можно доказать)

**Структура расширенного УТП:**
> Для кого → Что делает → Как работает → Почему лучше конкурентов

### Product Vision Statement (Moore's Elevator Pitch)

```
ДЛЯ [целевой аудитории],
КОМУ НУЖНО [потребность или возможность],
[НАЗВАНИЕ ПРОДУКТА] — это [категория продукта],
КОТОРЫЙ [ключевое преимущество, причина использования].
В ОТЛИЧИЕ ОТ [конкурент],
НАШ ПРОДУКТ [принципиальное отличие].
```

### 3. Product Vision Statement

**Для приоритетного сегмента:**

> **Для** [конкретная ЦА],  
> **кому нужно** [проблема/потребность],  
> **[Название продукта]** — это **[категория]**,  
> **который** [ключевое преимущество / главный Job, который выполняет].  
> **В отличие от** [главный конкурент или альтернативный способ],  
> **мы** [принципиальное отличие, измеримо].

*(Опционально: заполни для каждого сегмента)*

---

### 4. УТП (Уникальное Торговое Предложение)

**Краткое УТП** (1 предложение, ≤15 слов):
> «…»

**Расширенное УТП** (3–4 предложения):
```
[Для кого]: Для [ЦА], которые [ситуация/проблема].
[Что делает]: [Название] — это [краткое описание].
[Как работает]: [Ключевой механизм / технология / подход].
[Почему лучше]: В отличие от [конкуренты], мы [конкретное отличие].
```

**Проверка УТП — анти-паттерны:**
- ❌ «Лучшее на рынке» → замени на конкретику: «На 40% быстрее [конкурента]»
- ❌ «Уникальное предложение» → конкурент тоже так говорит
- ❌ «Для всех» → выбери конкретный сегмент

### 7. Обещание бренда (Brand Promise)

**Определение:** Одна фраза, описывающая ключевую ценность на эмоциональном уровне.

> «[Название продукта] — это [эмоциональное обещание].»

**Примеры обещаний брендов для референса:**
- Nike: «Just Do It» (ты можешь превзойти себя)
- Duolingo: «Учи язык бесплатно, весело и навсегда»
- Notion: «Один инструмент для всего»

**Проверочный вопрос:** «Если бы наш продукт был человеком — каким бы он был?»

### 8. Elevator Pitch (30 секунд)

Кратчайшее описание продукта для незнакомого человека:

> «[Название] — это [категория] для [ЦА], который помогает [Job]. 
> Мы делаем это за счёт [ключевая механика]. 
> В отличие от [альтернатива], мы [отличие]. 
> Уже [X пользователей / результат].»

## Фреймворки

- **Value Proposition Canvas** (Остервальдер) — Jobs / Pains / Gains + Products / Pain Relievers / Gain Creators
- **JTBD** (Клейтон Кристенсен) — функциональные, эмоциональные, социальные работы
- **Job Story** — «Когда я [ситуация], я хочу [мотивация], чтобы [результат]»
- **Product Vision Statement** (Moore's Elevator Pitch) — шаблон видения продукта
- **Product Vision Board** (Roman Pichler) — Vision / Target Group / Needs / Product / Business Goals

## Критерии качества

- [ ] Value Proposition Canvas заполнен для каждого сегмента (минимум 2 сегмента)
- [ ] Все 3 типа Job'ов описаны (функциональные, эмоциональные, социальные)
- [ ] Таблица Fit: каждая боль имеет Pain Reliever, каждая выгода — Gain Creator
- [ ] Job Story сформулирована для приоритетного сегмента
- [ ] УТП конкретное (нет «лучший», «уникальный», «инновационный»)
- [ ] Vision Statement заполнен по шаблону
- [ ] Ключевые сообщения адаптированы под каждый канал
- [ ] Бренд-атрибуты согласуются с позиционированием
