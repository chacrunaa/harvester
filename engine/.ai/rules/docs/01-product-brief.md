# Инструкция 01 — Описание продукта (бриф)

## Роль AI-агента

> Ты опытный продакт-менеджер и бизнес-аналитик с опытом запуска EdTech, SaaS и мобильных продуктов. Твоя задача — структурировать сырые материалы о продукте в чёткий бриф, используя фреймворки Product Vision Template и Product Vision Board.

## Теоретическая база (из курса «Создание продуктовой концепции», модуль 1)

### Что такое концепция продукта?

**Концепция продукта** — это система взглядов на будущий продукт. Детализированное описание идеи, поясняющее:
- Для кого предназначается будущий продукт
- В чём его ценность для пользователей
- В чём заключается предлагаемое решение и чем оно отличается от существующих
- За счёт чего продукт будет приносить прибыль

**Зачем фиксировать концепцию:**
1. Оценить целесообразность идеи до разработки
2. Синхронизировать команду и стейкхолдеров
3. Основа для технической документации
4. Точка отсчёта при изменении требований

### Иерархия понятий

```
Идея продукта
    ↓
Видение продукта  (каким продукт должен быть через 3–5 лет)
    ↓
Стратегия продукта  (план действий для достижения видения)
    ↓
Концепция продукта  (система взглядов на будущий продукт)
    ↓
Требования к продукту  (конкретные функции и характеристики)
```

**Видение продукта** — это то, каким в идеальных условиях должен быть ваш продукт через 3–5 лет с точки зрения пользователя. Примеры:
- Amazon: «Стать самой клиентоориентированной компанией, где клиенты могут найти всё»
- Apple: «Обеспечивать лучший пользовательский опыт с помощью инновационного оборудования»
- LinkedIn: «Создать экономические возможности для каждого участника глобального рынка труда»

### Product Vision Template (фреймворк)

Структурированный шаблон для описания видения продукта:

```
ДЛЯ: [целевой аудитории]
КОМУ НУЖНО: [потребность или возможность]
[НАЗВАНИЕ ПРОДУКТА]: [категория продукта]
КОТОРЫЙ: [ключевое преимущество, причина использования]
В ОТЛИЧИЕ ОТ: [конкурирующий альтернативный продукт]
НАШ ПРОДУКТ: [принципиальное отличие]
```

### Product Vision Board (Roman Pichler)

Расширенная версия для системного описания. 5 секций:

| Секция | Вопрос | Что заполнять |
|--------|--------|--------------|
| **Vision** | Каково видение? | Один абзац — почему продукт существует, чего хотим достичь |
| **Target Group** | Кто целевые пользователи? | Сегменты с демографией, поведением, потребностями |
| **Needs** | Какие потребности решаем? | Проблемы и Jobs to Be Done каждого сегмента |
| **Product** | Что это за продукт? | Ключевые функции, отличительные особенности |
| **Business Goals** | Каков бизнес-результат? | Как продукт принесёт пользу компании (выручка, рост, стратегия) |

## Входные данные

Передай агенту один или несколько документов из `docs/data/input/`:
- Описание идеи (текст, презентация, заметки)
- Переписку или обсуждения о продукте
- Любые наброски концепции
- Исследования рынка, данные о ЦА (если есть)

Если данных не хватает — агент задаёт уточняющие вопросы по структуре ниже.

## Задача

### 1. Аннотация

Одно предложение, описывающее продукт:

> **«[Название] — это [категория], который [ключевая ценность] для [ЦА], позволяющий [главный результат для пользователя].»**

---

### 2. Product Vision Statement

Заполни шаблон (Product Vision Template):

> **Для** [целевой аудитории],  
> **кому** [потребность / проблема / возможность],  
> **[название продукта]** — это **[категория продукта]**,  
> **который** [ключевое преимущество / причина использования].  
> **В отличие от** [главный конкурент или альтернативный подход],  
> **мы** [принципиальное отличие / дифференциация].

---

| Параметр | Значение |

| Вопрос | Ответ |
|--------|-------|

| Как решают проблему сейчас? (без вашего продукта) | … |
| Что происходит, если проблема не решена? | … |
| Почему именно сейчас подходящее время? | … (тренд/технология/изменение рынка) |

---

### 6. Product Vision Board

| Секция | Содержание |
|--------|-----------|
| **Vision (Видение)** | Одним абзацем: почему продукт существует, что хотим изменить в мире/жизни пользователей |
| **Target Group (ЦА)** | 2–3 сегмента с краткими описаниями |
| **Needs (Потребности)** | Топ-3 проблемы/JTBD для каждого сегмента |
| **Product (Продукт)** | 5–7 ключевых функций / особенностей |
| **Business Goals (Бизнес-цели)** | Выручка, рост пользователей, стратегическая цель |

---

### 7. Ключевые метрики успеха

Сформулируй 3–5 метрик с целевыми значениями:

| Метрика | Что измеряет | Текущий показатель | Цель (12 мес) | Бенчмарк отрасли |
|---------|-------------|-------------------|--------------|-----------------|
| Completion Rate | Доля завершивших курс | ~40% (рынок) | 70–80% | EdTech: 30–60% |
| NPS | Лояльность | — | ≥ 70 | Отлично > 50 |
| DAU/MAU (Sticky Factor) | «Прилипчивость» | — | ≥ 25% | EdTech: 15–25% |
| Retention D30 | Удержание | — | ≥ 30% | EdTech: 20–35% |
| Конверсия free→paid | Монетизация | — | ≥ 5% | Freemium: 2–5% |

## Формат вывода

Markdown-документ с заголовками по разделам выше. Объём: 1–2 страницы A4. Все утверждения подкреплены данными из входных материалов или обоснованными предположениями с пометкой `[гипотеза]`.

## Фреймворки

- **Product Vision Template** — «Для [ЦА], кому [потребность]...» (из курса «Создание продуктовой концепции»)
- **Product Vision Board** (Roman Pichler) — 5 секций: Vision / Target Group / Needs / Product / Business Goals
- **JTBD** (Jobs to Be Done) — что «нанимают» продукт сделать

## Критерии качества

- [ ] Vision Statement заполнен по шаблону Product Vision Template
- [ ] Product Vision Board заполнен по всем 5 секциям
- [ ] Проблема описана конкретно с данными или с пометкой [гипотеза]
- [ ] Решение напрямую закрывает описанную проблему
- [ ] Метрики имеют конкретные целевые значения с бенчмарком
- [ ] Ключевые гипотезы сформулированы с измеримыми критериями
- [ ] Документ не длиннее 2 страниц A4
