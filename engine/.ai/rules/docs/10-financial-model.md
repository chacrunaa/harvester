# Инструкция 10 — Финансовая модель

## Роль AI-агента

> Ты CFO и финансовый моделист с опытом построения финансовых моделей для стартапов. Твоя задача — построить PnL (отчёт о прибылях и убытках), CashFlow (бюджет движения денежных средств) на 12–36 месяцев с тремя сценариями.

## Теоретическая база (из курса «Экономика продукта», модуль 1)

### Зачем нужна финансовая модель продукту?

Финансовая модель позволяет ответить на ключевые вопросы:
- Насколько продукт прибыльный?
- Сколько потребуется инвестиций на первый год?
- Как увеличить прибыль, не увеличивая расходы?
- Как ещё можно зарабатывать на этом продукте?

Без финансовой модели решения принимаются на интуиции → риск потерять время и инвестиции на запуск неприбыльной фичи.

### Два ключевых финансовых документа

#### PnL (Profit and Loss) — Бюджет доходов и расходов (ОПиУ)

**Определение:** Документ, который отражает ожидаемые доходы и расходы компании за период.

**Задачи PnL:**
1. **Планировать** — прогноз доходов и расходов на любой период
2. **Контролировать** — сравнивать план с фактом, видеть отклонения
3. **Принимать решения** — об изменении стратегии, дополнительных инвестициях или сокращении расходов

**Структура расходов:**

```
Расходы
├── CAPEX (Capital Expenditure) — Капитальные расходы
│   └── Разовые затраты, которые амортизируются со временем
│       Примеры: разработка MVP, покупка оборудования, юридические расходы
│
└── OPEX (Operating Expenditure) — Операционные расходы
    ├── Постоянные (Fixed) — не зависят от оборота
    │   Примеры: ФОТ, аренда офиса, лицензии
    └── Переменные (Variable) — растут пропорционально бизнесу
        Примеры: маркетинг/привлечение, комиссии платёжных систем, налоги
```

**Ключевые строки PnL:**
```
Выручка (Revenue)
- Переменные затраты (Variable Costs)
= Валовая прибыль (Gross Profit)
  → Валовая маржа (%) = Gross Profit / Revenue × 100

- Фиксированные операционные затраты (Fixed OPEX)
= EBITDA (Earnings Before Interest, Taxes, Depreciation, Amortization)
  = Доходы минус расходы (кроме налогов и эквайринга)

- Амортизация CAPEX
= EBIT (операционная прибыль)

- Налоги и прочее
= Чистая прибыль (Net Profit)
```

#### CashFlow (ДДС) — Бюджет движения денежных средств

**Определение:** Документ, отражающий реальные поступления и выплаты денег за период.

> **Важное отличие от PnL:** Компания может быть прибыльной по PnL, но иметь кассовый разрыв (денег нет, хотя прибыль есть). CashFlow показывает реальное движение денег.

**3 потока CashFlow:**

| Поток | Что включает | Примеры |
|-------|------------|---------|
| **Операционный** | Деньги от основной деятельности | Оплаты от клиентов, выплаты команде, маркетинг |
| **Инвестиционный** | Капитальные вложения и их возврат | Разработка MVP (CAPEX), закупка оборудования |
| **Финансовый** | Привлечение и возврат финансирования | Инвестиции учредителей, кредиты |

**Ключевые поля CashFlow:**
```
Остаток на начало периода
+ Поступления (всего)
  + Выручка от клиентов
  + Взносы учредителей / инвестиции
- Выплаты (всего)
  - Операционные затраты
  - CAPEX
= Сальдо за период
= Остаток на конец периода (→ переходит в следующий месяц как Остаток на начало)
```

> **Риск:** Если «Остаток на конец» уходит в минус — бизнес не может работать, даже если PnL показывает прибыль. Классический сценарий: вложено 1 млн руб, по PnL выход в плюс через 6 месяцев, но по CashFlow денег не хватает уже через 3 месяца. Правильное финансирование рассчитывается именно через CashFlow.

### Break-Even (Точка безубыточности)

**Break-even** — момент, когда выручка покрывает все расходы (EBITDA = 0 или CashFlow ≥ 0 накопленно).

**По PnL:** Месяц, когда ежемесячный EBITDA становится ≥ 0  
**По CashFlow:** Месяц, когда кумулятивный остаток восстанавливается до начальных инвестиций (возврат инвестиций, ROI)

```
Break-even по MRR:
MRR_BE = Фиксированные ежемесячные расходы / Gross Margin (%)

Например: OPEX Fixed = 500 000 руб/мес, GM = 70%
MRR_BE = 500 000 / 0.7 = ~714 000 руб/мес
```

## Фреймворки

- **PnL (ОПиУ)** — бюджет доходов и расходов: Выручка → Валовая прибыль → EBITDA → Чистая прибыль
- **CashFlow (ДДС)** — движение денег: Операционный + Инвестиционный + Финансовый потоки
- **CAPEX / OPEX (Fixed + Variable)** — классификация расходов
- **Break-even** — по PnL (ежемесячная прибыль) и CashFlow (возврат инвестиций)
- **Три сценария** — Bear / Base / Bull с явными допущениями
- **Анализ чувствительности** — ключевые драйверы финансовых результатов

## Критерии качества

- [ ] PnL содержит все строки: Выручка → Валовая прибыль → EBITDA → Чистая прибыль
- [ ] CashFlow разделён на 3 потока: операционный, инвестиционный, финансовый
- [ ] Чётко разделены CAPEX и OPEX (Fixed vs Variable)
- [ ] Break-even указан в конкретном месяце ДЛЯ ОБОИХ документов
- [ ] Три сценария с явными допущениями (Bear / Base / Bull)
- [ ] Анализ чувствительности выявляет ключевые драйверы
- [ ] Все числа согласованы с юнит-экономикой (инструкция 08)
- [ ] Резюме для инвестора содержит ответ на вопрос об объёме инвестиций
