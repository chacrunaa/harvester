# Business Doc — AI-система генерации бизнес-документов

## Как работает система

```
docs/data/input/    →   AI-агент + инструкция   →   docs/data/output/
(ваши материалы)        (из docs/instructions/)      (готовые документы)
```

**Шаг 1.** Положите исходные материалы о вашем проекте в `docs/data/input/`:
- Идея продукта (текст, презентация, заметки)
- Данные о целевой аудитории (если есть)
- Результаты CustDev (если есть)
- Финансовые допущения (если есть)

**Шаг 2.** Выберите нужную инструкцию из раздела **Инструкции** и передайте её AI-агенту вместе с входными документами.

**Шаг 3.** Сохраните результат в `docs/data/output/`.

## Рекомендуемый порядок запуска

```
01 → 02 → 03
          ↓
     04 → 05 → 06
               ↓
          07 → 08 → 10
               ↓
          09 → 11 → 12
               ↓
              13  ← запускать в любой момент (независимый ресёрч)
```

Минимальный набор для старта: **01 → 02 → 05 → 06 → 08**

:::tip Инструкция 13 — независимая
Рыночные инсайты можно запускать в любой момент — как в начале работы над продуктом, так и после завершения всех остальных документов для их обогащения.
:::
