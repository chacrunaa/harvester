# Инструкция 08 — Юнит-экономика

## Роль AI-агента

> Ты финансовый аналитик и продуктовый экономист с опытом работы в финтехе и EdTech. Твоя задача — рассчитать экономику одного «юнита» с полным раскрытием формул, показать точку безубыточности и сценарный анализ. Все расчёты должны быть прозрачными и воспроизводимыми.

## Теоретическая база (из курса «Экономика продукта», Эрик Меликян)

**Ключевые концепции:**

- **Юнит-экономика** — это расчёт экономики одного «юнита» (пользователя, транзакции, подписки) для оценки прибыльности бизнес-модели в масштабе
- **ARPU** (Average Revenue Per User) = Суммарная выручка / Количество активных пользователей
- **ARPPU** (Average Revenue Per Paying User) = Суммарная выручка / Количество платящих пользователей
- **CAC** (Customer Acquisition Cost) = Расходы на привлечение / Количество привлечённых клиентов
- **LTV** (Lifetime Value) = Доход от одного клиента за всё время взаимодействия
- **Churn Rate** = Процент пользователей, которые перестали пользоваться продуктом за период
- **Retention Rate** = 1 − Churn Rate

**Декомпозиция выручки на 6 факторов** (по курсу):
```
Выручка = Кол-во пользователей × Конверсия в платёж × Средний чек
           × Частота покупок × (1 − Churn) × Маржа
```

### 3. Расчёт LTV

**Три метода — используй все три для перекрёстной проверки:**

**Метод 1 — Простой (через ARPU и Churn):**
```
LTV = ARPU(monthly) × Gross Margin / Monthly Churn Rate
```

**Метод 2 — Через среднее время жизни клиента:**
```
Customer Lifetime = 1 / Monthly Churn Rate (в месяцах)
LTV = ARPU(monthly) × Gross Margin × Customer Lifetime
```

**Метод 3 — Когортный (наиболее точный):**
```
LTV = Σ (ARPU × Gross Margin × Retention_Rate_в_месяц_N)
      для всех месяцев N от 0 до конца жизни когорты
```

| Параметр | Значение | Источник |
|---|---|---|
| ARPU (ежемесячный) | … руб | Тарифная сетка / данные |
| Gross Margin | …% | Структура затрат |
| Monthly Churn Rate | …% | Бенчмарк или гипотеза |
| Monthly Retention Rate | = 1 − Churn | — |
| Customer Lifetime | = 1/Churn | … мес |
| **LTV (Метод 1)** | **… руб** | |
| **LTV (Метод 2)** | **… руб** | |

**Бенчмарки Churn Rate по отраслям:**
- EdTech (онлайн-курсы): 8–15% в месяц
- SaaS B2C: 5–10% в месяц
- SaaS B2B: 1–3% в месяц
- Мобильные игры: 15–25% в месяц

### 4. LTV/CAC Ratio и Payback Period

**Формулы:**
```
LTV/CAC Ratio = LTV / CAC

Payback Period = CAC / (ARPU × Gross Margin)
(в месяцах — сколько месяцев нужно, чтобы окупить CAC)
```

**Интерпретация LTV/CAC:**

| LTV/CAC | Интерпретация | Действие |
|---|---|---|
| < 1x | Каждый клиент приносит убыток | Стоп. Пересмотр модели |
| 1x – 3x | Бизнес убыточен или на грани | Снизить CAC или поднять LTV |
| 3x – 5x | Здоровый бизнес | Масштабировать |
| > 5x | Очень высокая эффективность | Агрессивный рост |

**Payback Period:**
- ≤ 6 месяцев — отлично для B2C
- 6–12 месяцев — норма
- 12–18 месяцев — приемлемо для B2B
- > 24 месяцев — критично, риск кассового разрыва

### 5. Конверсионная воронка (PnL на уровне одного привлечённого пользователя)

Покажи экономику на одного привлечённого пользователя пошагово:

```
1. Вложено на привлечение:        −CAC руб
2. Пользователь активировался:    +0 (ещё не платит)
3. Первая оплата (M1):            +ARPU × Gross Margin руб
4. Вторая оплата (M2, Retention): +ARPU × Gross Margin × Retention руб
5. ...
6. Суммарно за N месяцев:         LTV руб
7. Чистая прибыль на клиента:     LTV − CAC руб
```

**Формула:**
```
Break-even (пользователей) = Фиксированные затраты / Contribution Margin на юнит
Contribution Margin = ARPU − Переменные затраты на 1 пользователя
```
