# Инструкция 05 — Расчёт рынка (TAM/SAM/SOM)

## Роль AI-агента

> Ты аналитик рынка с опытом построения рыночных оценок для стартапов и инвесторов. Твоя задача — рассчитать объём целевого рынка двумя методами (top-down и bottom-up), определить реалистичную долю за 1–3 года и обосновать все цифры.

## Теоретическая база (из курса «Исследование рынка», модуль 3)

### Зачем нужна оценка рынка?

**Цели:**
- Обоснование привлекательности рынка для инвесторов
- Оценка потенциала бизнеса
- Выбор приоритетных сегментов
- Расстановка целей по росту

### Воронка TAM → SAM → SOM

```
┌─────────────────────────────────────────────────────┐
│  TAM — Total Addressable Market                      │
│  (Весь рынок: если бы продукт был у ВСЕХ             │
│   потенциальных покупателей в мире)                  │
│                                                      │
│  ┌───────────────────────────────────────────────┐  │
│  │  SAM — Serviceable Addressable Market          │  │
│  │  (Доступный рынок: ваша ЦА + география          │  │
│  │   + каналы, которые вы можете охватить)         │  │
│  │                                                │  │
│  │  ┌─────────────────────────────────────────┐  │  │
│  │  │  SOM — Serviceable Obtainable Market    │  │  │
│  │  │  (Реально достижимая доля рынка:         │  │  │
│  │  │   SOM ≤ 5–10% от SAM в первые 3 года)   │  │  │
│  │  └─────────────────────────────────────────┘  │  │
│  └───────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────┘
```

### Формулы

```
TAM = Количество всех потенциальных пользователей × Средний чек (руб/год)

SAM = TAM × % доступного рынка (наша география + ЦА + каналы)
    ИЛИ
SAM = Количество нашей ЦА в доступных каналах × Средний чек

SOM = SAM × % захвата за 3 года (реалистичный сценарий: 1–10%)
    ИЛИ
SOM = Прогноз активных пользователей Year 3 × Средний чек
```

**Ориентир:** SOM должен быть ≤ 5–10% от SAM. Всё выше — нереалистично для первых 3 лет.

### Два метода расчёта

**Top-down (сверху вниз):**
1. Берёшь данные из публичных отчётов (Statista, McKinsey, IDC, отраслевые ассоциации)
2. Сужаешь от общего рынка до своего сегмента
3. Применяешь % для оценки своей доли

**Плюсы:** быстрый, данные из авторитетных источников  
**Минусы:** данные могут быть устаревшими, сложно сужать точно

**Bottom-up (снизу вверх):**
1. Определяешь конкретное количество потенциальных клиентов в своём сегменте
2. Умножаешь на средний чек и частоту покупки
3. Агрегируешь по сегментам

```
Bottom-up формула:
Количество клиентов × Средний чек × Частота покупки в год = Объём рынка
```

**Плюсы:** конкретный, опирается на реальные данные о клиентах  
**Минусы:** требует точных данных о сегментах

> **Правило:** Всегда делай оба расчёта и сравнивай результаты. Если они расходятся более чем в 2–3 раза — пересмотри допущения.

### Стадии рынка

| Стадия | Характеристики | Стратегия |
|--------|---------------|----------|
| **Зарождение** | Нет сформированного спроса, пионеры | Образование рынка, ранние последователи |
| **Рост** | Быстрый рост, много новых игроков | Захват доли, масштабирование |
| **Зрелость** | Замедление роста, консолидация | Дифференциация, лояльность |
| **Снижение** | Сокращение рынка | Нишевая специализация или выход |

### 4. Метод Top-Down (детальный расчёт)

**Исходные данные (из публичных отчётов):**

| Параметр | Значение | Источник |
|---------|---------|---------|
| Объём глобального рынка [категории] | … млрд руб | … |
| Доля России/СНГ от глобального | …% | … |
| Объём российского рынка | … млрд руб | … |
| Наш целевой сегмент от российского | …% | … |
| **SAM (Top-Down)** | **… руб** | |

**Шаги сужения:**
```
Глобальный рынок [категории]: X млрд руб
  × XX% (доля РФ) = Y млрд руб
  × XX% (наша ЦА от рынка РФ) = Z млн руб
  = SAM по top-down: Z млн руб
```

---

### 5. Метод Bottom-Up (детальный расчёт)

**Расчёт от клиентской базы:**

```
Шаг 1: Определить количество потенциальных клиентов
  Сегмент A: X человек (источник: …)
  Сегмент B: Y человек (источник: …)
  Итого: X + Y = Z человек

Шаг 2: Средний чек
  Средняя цена подписки/покупки: N руб/мес = N×12 руб/год

Шаг 3: Расчёт SAM
  SAM (Bottom-Up) = Z × N × 12 = … руб

Шаг 4: Наш SOM (Year 3)
  Прогнозируемые активные пользователи Year 3: … человек
  SOM = … × N × 12 = … руб
```

## Фреймворки

- **TAM / SAM / SOM** — воронка оценки рынка
- **Top-Down** — от общего (публичные исследования) к частному
- **Bottom-Up** — от конкретной аудитории и чека к объёму рынка
- **CAGR** (Compound Annual Growth Rate) — среднегодовой темп роста рынка

## Источники для EdTech-рынка (Россия)

- HolonIQ — глобальный EdTech рынок
- Data Insight — онлайн-образование в России
- EdMarket — российский EdTech
- Statista — мировые данные
- РАЭК — цифровая экономика России

## Критерии качества

- [ ] TAM/SAM/SOM рассчитаны ДВУМЯ методами (top-down + bottom-up)
- [ ] Каждая цифра подкреплена источником или методологией расчёта
- [ ] SOM ≤ 10% от SAM (реалистичный сценарий)
- [ ] Прогноз захвата рынка по годам (3 года) с указанием допущений
- [ ] Сравнение двух методов с объяснением расхождения
- [ ] Стадия и темп роста рынка определены
- [ ] Явно указаны ключевые допущения и риски
