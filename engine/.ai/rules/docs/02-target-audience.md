# Инструкция 02 — Анализ целевой аудитории

## Роль AI-агента

> Ты UX-исследователь, маркетолог и специалист по продуктовому подходу. Твоя задача — системно описать потребительские сегменты, их Jobs to Be Done, боли и существующие решения. Используй данные из входных материалов, а там, где данных нет — формулируй обоснованные гипотезы с пометкой `[гипотеза]`.

## Теоретическая база

**Jobs to Be Done (JTBD)** — подход, разработанный Клейтоном Кристенсеном. Суть: пользователь «нанимает» продукт для выполнения работы. Конкурируют не продукты — конкурируют способы выполнения одной и той же «работы».

**Типы Job'ов:**
- **Функциональные** — конкретная задача (выучить Python за 3 месяца)
- **Эмоциональные** — как хочет себя чувствовать (уверенным в новой профессии)
- **Социальные** — как хочет выглядеть в глазах других (продвинутым специалистом)

**Job Story (шаблон JTBD):**
> Когда я **[ситуация/триггер]**, я хочу **[мотивация/цель]**, чтобы **[желаемый результат]**.

**Критерии хорошей сегментации:**
1. Сегменты реально различаются по поведению и потребностям
2. Сегмент достаточно велик для бизнеса
3. К сегменту можно обратиться через отдельный канал
4. Сегмент можно описать измеримыми характеристиками

## Входные данные

- Бриф продукта (инструкция 01)
- Результаты CustDev / интервью (если есть)
- Данные из опросов (если есть)
- Данные из `.notes/materials/` о ЦА и CustDev

### 3. Персоны (для каждого приоритетного сегмента)

**Шаблон персоны:**

**Возраст:** …  **Город:** …  **Профессия:** …  **Доход:** …

**Ситуация:**

**Цели (Jobs):**
- Функциональная цель: «Хочу ___ потому что ___»
- Эмоциональная цель: «Хочу чувствовать себя ___»
- Социальная цель: «Хочу выглядеть/восприниматься как ___»

**Боли (Pains):**
- Главная боль: …
- Дополнительные боли: …
- Страхи: …

**Потребности (Gains):**
- Минимальные ожидания: …
- Желаемые выгоды: …
- Неожиданные приятные бонусы: …

**Текущее поведение:**
Как решает проблему сейчас (без нашего продукта)?

**Job Story:**
> Когда я **[ситуация]**, я хочу **[мотивация]**, чтобы **[результат]**.

---

### 4. Проблемы сегментов и существующие решения

Для каждого сегмента заполни полную таблицу:

| Потребность | Проблема | Причина проблемы | Существующее решение (конкурент) | Минусы существующего | Ресурсы (время/$) на решение |
|---|---|---|---|---|---|

**Вопросы для анализа:**
- Как пользователь решает проблему прямо сейчас?
- Что его не устраивает в существующих решениях?
- Сколько времени/денег он тратит?
- Что произойдёт, если он НЕ решит проблему?

---

### 5. Jobs to Be Done — полный анализ

Для каждого сегмента:

**Job Map (карта работы пользователя):**
1. Определить потребность
2. Найти информацию / варианты
3. Принять решение
4. Использовать продукт
5. Оценить результат
6. Решить: продолжить / уйти

**На каком шаге наш продукт помогает больше всего?**

**JTBD-конкуренция:**  
Кто ещё «выполняет эту работу» для пользователя? Неочевидные конкуренты?  
*(Пример: Duolingo конкурирует не только с другими языковыми приложениями, но и с YouTube, подкастами, частными репетиторами)*

### 7. Гипотезы для проверки через CustDev

Сформулируй гипотезы по шаблону курса:

> **Мы верим, что** [предположение о проблеме или поведении].  
> **Чтобы это проверить,** [конкретные действия].  
> **И измерим** [инструмент / метрика].  
> **Мы окажемся правы, если** [критерий подтверждения].

| # | Гипотеза | Тип | Критерий подтверждения |
|---|---|---|---|
| 1 | … | О потребности | … |
| 2 | … | О продукте | … |
| 3 | … | О бизнес-модели | … |
| 4 | … | О рынке | … |

**Типы гипотез (по курсу «Тестирование гипотез»):**
- **О потребностях** — какие проблемы у пользователей
- **О продукте** — какие функции нужны
- **О конкурентной среде** — чем выделиться
- **О бизнес-модели** — как монетизировать
- **О рынке** — тренды, размер, доступность

## Фреймворки

- **Jobs to Be Done** (Клейтон Кристенсен) — «нанять продукт для выполнения работы»
- **Персоны** — архетипы типичных пользователей
- **Value Proposition Canvas** — Профиль Клиента (Jobs, Pains, Gains)
- **Пирамида Маслоу** — привязка потребностей к уровням мотивации (физиологические → самоактуализация)

## Критерии качества

- [ ] Выделено 2–4 различных сегмента с реальными различиями в поведении
- [ ] Каждая персона содержит конкретные данные (числа, цитаты, ситуации)
- [ ] Job Story сформулирована от первого лица для каждого сегмента
- [ ] Таблица «проблемы → существующие решения → минусы» заполнена для всех сегментов
- [ ] Приоритетный сегмент обоснован по 5 критериям
- [ ] Гипотезы сформулированы по шаблону с измеримыми критериями
