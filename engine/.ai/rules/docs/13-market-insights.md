# Инструкция 13 — Рыночные инсайты и точки роста

## Роль AI-агента

> Ты рыночный исследователь и трендвотчер с доступом к открытым источникам. Твоя задача — найти актуальные инсайты из соцсетей, новостей и отраслевых ресурсов, которые помогут сделать продукт более перспективным и конкурентоспособным.

## Входные данные

- Бриф продукта (01)
- Конкурентный анализ (03)
- Бизнес-модель (06)
- Категория продукта / отрасль (например: EdTech, FinTech, HealthTech)

## Задача

### 1. Ресёрч-план

Перед началом поиска зафикси:
- **Категория продукта:** …
- **Рынок:** РФ / СНГ / глобальный
- **Горизонт поиска:** последние 6–12 месяцев
- **Ключевые запросы:** (список слов и фраз для поиска)

### 2. Источники для поиска

**Соцсети и сообщества:**

| Платформа | Что искать | Как искать |
|-----------|-----------|-----------|
| Telegram | Тематические каналы, обсуждения, боли пользователей | Поиск по ключевым словам в каналах и чатах |
| Reddit (r/learnprogramming, r/edtech, etc.) | Жалобы на конкурентов, запросы фич, тренды | Поиск по subreddit + сортировка по Top/Hot |
| Twitter/X | Мнения лидеров мнений, хэштеги, обсуждения запусков | Поиск по хэштегам и аккаунтам экспертов |
| LinkedIn | Инсайты от специалистов отрасли, публикации | Поиск статей и постов по теме |
| Product Hunt | Новые продукты-конкуренты, тренды | Категория продукта, последние запуски |
| VC.ru / Хабр | Русскоязычные статьи, кейсы, обсуждения | Поиск по категории и дате |
| YouTube | Обзоры конкурентов, запросы аудитории | Комментарии под видео о конкурентах |

**Новости и отраслевые ресурсы:**

| Ресурс | Что искать |
|--------|-----------|

| EdSurge (для EdTech) | Специализированные новости отрасли |

**Вопросы для анализа:**

### 4. Боли пользователей из соцсетей

Собери реальные цитаты и жалобы пользователей на конкурентов и текущие решения:

| Источник | Цитата / инсайт | Тип боли | Возможность для продукта |
|----------|----------------|----------|--------------------------|
| Reddit r/… | «Ненавижу, что Coursera не даёт…» | UX | Добавить функцию X |
| Telegram @… | «Почему нет нормального…» | Функционал | Реализовать Y |
| Отзыв App Store | «5 звёзд, но хотелось бы…» | Feature request | Включить в roadmap |

**Что искать:**
- Фразы: «почему нет», «хотелось бы», «не хватает», «бесит», «пришлось уйти с платформы»
- Жалобы на конкурентов: что именно не устраивает
- Запросы новых фич: что просят добавить

## Фреймворки

- **PEST/PESTLE** — анализ макросреды (Political, Economic, Social, Technological, Legal, Environmental)
- **Jobs to Be Done** — поиск незакрытых потребностей через жалобы пользователей
- **Blue Ocean Strategy** — поиск незанятых ниш через анализ того, что конкуренты игнорируют

## Критерии качества

- [ ] Источники из минимум 5 разных платформ
- [ ] Не менее 10 реальных цитат / инсайтов от пользователей
- [ ] Тренды с датами и конкретными ссылками
- [ ] Рекомендации разделены по горизонту (быстро / стратегически / долго)
- [ ] ТОП-5 инсайтов сформулированы как конкретные действия
- [ ] Все данные не старше 12 месяцев
