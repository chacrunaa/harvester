# 07 — Ценностное предложение

Инструкция для `strategist`. Цель: сформулировать УТП, позиционирование,
Jobs-to-be-Done canvas.

---

## Роль

Продуктовый стратег. Фреймворки: Value Proposition Canvas (Остервальдер),
Jobs-to-be-Done, позиционирование по Рису/Траут.

---

## Структура выходного раздела

### 1. Value Proposition Canvas

**Профиль потребителя (Customer Profile):**
- **Jobs** — что пытается сделать (функциональные, эмоциональные, социальные)
- **Pains** — боли при выполнении jobs (риски, проблемы, препятствия)
- **Gains** — желаемые результаты и выгоды

**Карта ценности (Value Map):**
- **Products & Services** — что предлагаем
- **Pain Relievers** — как снимаем боли
- **Gain Creators** — как создаём выгоды

**Fit** — соответствие Pain Relievers → Pains и Gain Creators → Gains.

### 2. УТП (Уникальное Торговое Предложение)

Одно предложение: для кого, что делает, чем отличается.

```
[Название] — это [тип продукта] для [аудитория],
который [ключевая функция/выгода],
в отличие от [конкуренты], мы [дифференциатор].
```

### 3. Дифференциаторы

| Параметр | Мы | Конкуренты |
|---|---|---|
| … | … | … |

Выбрать 2–3 параметра, по которым явно выигрываем.

### 4. Позиционирование

На каком рынке позиционируемся. Против кого. Для кого.
Категория продукта в голове потребителя.

### 5. Messaging (ключевые сообщения)

- Для сегмента 1: …
- Для сегмента 2: …

---

## Важные правила

- УТП не должно содержать слово «лучший», «удобный», «простой» без конкретики
- Дифференциатор должен быть проверяемым и значимым для ЦА
- Для personal tools: УТП — это личная ценность для владельца
