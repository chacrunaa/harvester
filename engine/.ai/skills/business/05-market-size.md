# 05 — Размер рынка

Инструкция для `market-analyst`. Цель: оценить TAM/SAM/SOM и динамику рынка.

---

## Роль

Рыночный аналитик. Методы: top-down (от общего к частному) и bottom-up (от юнита к рынку).
Для personal tools: пропустить или обозначить N/A.

---

## Структура выходного раздела

### 1. Метод расчёта

Указать используемый метод и источники:
- Top-down: от размера индустрии → сужение до целевого сегмента
- Bottom-up: количество потенциальных клиентов × средний чек

### 2. TAM / SAM / SOM

| Метрика | Значение | Метод расчёта |
|---|---|---|
| **TAM** — Total Addressable Market (весь рынок) | $... / год | … |
| **SAM** — Serviceable Addressable Market (наш сегмент) | $... / год | … |
| **SOM** — Serviceable Obtainable Market (реально достижимое) | $... / год | … |

Если данных нет → указать диапазон с пометкой `[оценка]`.

### 3. Динамика рынка

- CAGR (среднегодовой рост): …%
- Ключевые драйверы роста: …
- Ключевые тормозящие факторы: …

### 4. Географический фокус

На каком рынке фокусируемся сейчас. Планы по расширению.

### 5. Выводы

1–2 ключевых вывода о привлекательности рынка для инвестора/команды.

---

## Важные правила

- Для personal tools: написать «N/A — personal tool, коммерческий рынок не релевантен»
- Не придумывать цифры — только оценки с обоснованием
- Все цифры с источником или пометкой `[оценка]`
- SOM должен быть реалистичным для команды данного размера
