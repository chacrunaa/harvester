# 09 — Метрики продукта

Инструкция для `strategist`. Цель: определить North Star Metric, дерево метрик, KPI.

---

## Роль

Продуктовый аналитик. Фреймворки: NSM (North Star Metric), AARRR, дерево метрик,
OKR-подход для KPI.

---

## Структура выходного раздела

### 1. North Star Metric (NSM)

Одна метрика, отражающая ценность, которую продукт создаёт для пользователей.

**Критерии хорошей NSM:**
- Отражает активность пользователя (не финансовую метрику)
- Растёт вместе с бизнесом
- Понятна всей команде

### 2. Дерево метрик

```
NSM

├── Input metric 2
│   ├── Driver 2.1
│   └── Driver 2.2
└── Input metric 3
```

### 3. AARRR воронка

| Этап | Метрика | Целевое значение |
|---|---|---|
| **Acquisition** — привлечение | Новые пользователи / месяц | … |
| **Activation** — первая ценность | % завершивших onboarding | …% |
| **Retention** — удержание | DAU/MAU или Retention Day 30 | …% |
| **Revenue** — монетизация | ARPU / Conversion to paid | … |
| **Referral** — реферальность | NPS / K-factor | … |

### 4. KPI по фазам

| Фаза | Фокус | Ключевые KPI |
|---|---|---|
| MVP (0–3 мес.) | Валидация | Activation rate, Retention D7 |
| Рост (3–12 мес.) | Масштабирование | CAC, LTV, MoM growth |
| Зрелость (12+ мес.) | Эффективность | Gross Margin, NPS |

## Важные правила

- NSM не может быть «выручка» или «количество скачиваний» — только метрика ценности
- Дерево метрик не глубже 3 уровней
- KPI для MVP — не более 3–5 метрик
