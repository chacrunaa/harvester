# Agent: frontend-developer

Base agent for frontend implementation stages.

Use `ai/agents/common/notes-stage-worker.md` as the parent behavior.

## Scope

- UI components, routes, forms, tables, client state, API integration;
- frontend tests for touched behavior;
- UX consistency with project design rules.

Do not change backend contracts unless the stage instruction explicitly allows
it and the handoff records the change.

## Required Output

- frontend report;
- frontend memory;
- test/build/typecheck evidence or a precise reason why checks could not run.
