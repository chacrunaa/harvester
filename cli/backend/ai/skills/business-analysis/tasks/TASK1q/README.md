# tasks/TASK1q — Задания для обработки ответов на вопросы TASK1

Эта директория содержит задания, которые AI-агент создаёт **одновременно** с формированием вопросов в `questions/`.

Логика: когда вопросы сформированы и сохранены в `questions/`, агент не просто ждёт ответов — он сразу создаёт задание-инструкцию, которое объяснит что делать с ответами, когда они придут.

---

## Когда появляются файлы здесь

Файлы создаются в `tasks/TASK1q/` **только если** в ходе TASK1 были сформированы вопросы.

Если вопросов не возникло (данных достаточно) — директория остаётся пустой, это норма.

---

## Формат файлов

**Имя файла:** `q1.md`, `q2.md`, `q3.md` — по номеру раунда вопросов.

**Структура каждого файла:**

```markdown
# Q[N] — Задание по обработке ответов на вопросы [дата]

## Что нужно сделать

Прочитать ответы клиента на вопросы из файла: `questions/[имя-файла-с-вопросами]`

Затем структурировать полученную информацию и сохранить в `data/info/`.

## Какие вопросы были заданы

[Краткое резюме тем вопросов — чтобы было понятно без открытия questions/]

## Что именно создать в data/info/

Создать файл: `data/info/[дата]-[тема]-analysis.md`

Этот файл должен содержать:
- Структурированные факты (то, что клиент подтвердил однозначно)
- Гипотезы (то, что клиент не знает / оценивает приблизительно) — с пометкой [гипотеза]
- Противоречия в ответах — если есть, явно отметить
- Пробелы, которые ответ не закрыл — если вопрос остался без ответа

## Критерии готовности

- [ ] Файл в data/info/ создан
- [ ] Каждый ответ структурирован (факт / гипотеза / противоречие)
- [ ] Нет сырого copy-paste ответов клиента — только обработанная информация
- [ ] После обработки снова оценить: остались ли критичные пробелы?
```

---

## Пример реального файла

**Файл:** `tasks/TASK1q/q1.md`

```markdown
# Q1 — Задание по обработке ответов на вопросы (2024-11-15)

## Что нужно сделать

Прочитать ответы клиента из файла: `questions/2024-11-15-audience-pricing.txt`

Структурировать информацию и создать: `data/info/2024-11-15-audience-pricing-analysis.md`

## Какие вопросы были заданы

Блок 1 — Целевая аудитория:
- Кто именно является основным покупателем?
- Как пользователь узнаёт о проблеме?
- Есть ли уже интервью или feedback?

Блок 2 — Ценообразование:
- Какова базовая цена услуги?
- Есть ли опции upsell? Какова их стоимость?
- Какой процент пользователей берёт upsell?

## Что создать в data/info/

Файл: `data/info/2024-11-15-audience-pricing-analysis.md`

Структура файла:
- Факты по ЦА: [всё, что подтверждено]
- Ценообразование: [цены, конверсии — отдельно факт / гипотеза]
- Что осталось неясным: [список]

## Критерии готовности

- [ ] Файл data/info/2024-11-15-audience-pricing-analysis.md создан
- [ ] Факты отделены от гипотез
- [ ] Повторно оценено: можно переходить к TASK3 или нужен ещё один раунд вопросов?
```

---

## Связь с другими файлами

```
TASK1.md
  → создаёт вопросы в questions/[дата]-[тема].txt
  → создаёт задание здесь: tasks/TASK1q/q1.md
       ↓
  Клиент отвечает на вопросы
       ↓
  tasks/TASK1q/q1.md → инструктирует обработать ответы → data/info/[файл]
       ↓
  Если закрыты все пробелы → TASK2.md
  Если нет → TASK1.md снова (создаётся q2.md)
```
