# TASK5 — Итоговое аналитическое заключение

## Суть задания

Подготовить итоговый аналитический отчёт по проекту: оценить жизнеспособность бизнеса, вероятность успеха, ключевые риски и возможности, а также конкретные рекомендации по направлениям роста. TASK5 запускается **после** TASK3 и (опционально) TASK4.

**Выходной файл:** `data/output/00-analytics/00-final-analysis.md`

**Главный принцип:** Это не резюме предыдущих документов. Это синтез — выводы, которые появляются только когда смотришь на всё вместе.

## Требования к качеству

- Scorecard — оценка по 7 факторам с обоснованием, каждая оценка привязана к конкретным данным
- Сценарный анализ — три сценария с конкретными условиями и финансовыми итогами
- Топ-5 рисков — с числовой оценкой вероятности и конкретными митигациями
- Возможности — разделены на «быстрые победы» и «стратегические»
- 90-дневный план — конкретные действия с дедлайнами и KPI
- Рекомендация GO/ITERATE/PIVOT/STOP — однозначная, с обоснованием

## Что НЕ делать

- Не пересказывать предыдущие документы — только синтез и новые выводы
- Не давать расплывчатые рекомендации («улучшить retention» без конкретики)
- Не ставить оценку в Scorecard без опоры на данные из входных документов
- Не пропускать раздел 8 — итоговое решение GO/STOP обязательно
- Не ограничиваться одним сценарием — показать весь диапазон исходов
