# TASK4 — Доменный анализ (Domain-Specific Analysis)

## Суть задания

Выполнить дополнительный анализ, специфичный для типа бизнеса данного проекта. TASK4 запускается **после** завершения TASK3 (основные 14 документов готовы в `data/output/`).

**Главный принцип: тот же, что в TASK3 — КАЧЕСТВО ВАЖНЕЕ СКОРОСТИ.** Каждый доменный документ должен быть не менее детальным, чем документы основного анализа.

---

## Шаг 1 — Определить тип бизнеса

Прочитать `data/info/` и `data/output/06-business-model/06-business-model.md`, чтобы определить тип бизнеса:

| Тип бизнеса | Признаки | Доменная директория |
|------------|---------|-------------------|
| **marketplace** | Две стороны (поставщики + покупатели), GMV-модель, take rate | `instructions/domains/marketplace/` |
| **ecommerce** | Продажа товаров (физических или цифровых), SKU/каталог, доставка | `instructions/domains/ecommerce/` |
| **b2b-saas** | Клиенты — компании, ARR/подписка, enterprise sales | `instructions/domains/b2b-saas/` |
| **mobile-app** | Основной канал — мобильное приложение, DAU-центричная модель | `instructions/domains/mobile-app/` |

**Если проект подходит под несколько типов — запустить анализ для каждого.**

Если тип бизнеса не совпадает ни с одним из перечисленных — написать в `data/output/15-domains/README.md` обоснование и предложить структуру анализа самостоятельно.

---

## Шаг 2 — Выполнить доменный анализ

### Вариант A — Через суб-агентов (предпочтительный)

Для каждого определённого домена — запустить суб-агента:
1. Передать полное содержимое инструкции из `instructions/domains/[домен]/`
2. Передать все входные файлы, указанные в инструкции
3. Создать папку `data/output/15-domains/[домен]/` если её нет
4. Результат сохранить в `data/output/15-domains/[домен]/`

### Вариант B — Самостоятельное выполнение

1. Открыть инструкцию из `instructions/domains/[домен]/`
2. Прочитать все входные файлы
3. Создать папку `data/output/15-domains/[домен]/` если её нет
4. Выполнить полностью, без сокращений
5. Сохранить в `data/output/15-domains/[домен]/`

## Обязательные требования к каждому доменному документу

### Содержание
- Все разделы из соответствующей инструкции — без исключений
- Все расчёты показаны явно: формула + подстановка чисел + результат
- Три сценария (Bear/Base/Bull) для финансовых таблиц
- Реальные данные из `data/info/` приоритетны над допущениями

### Запрещено
- Пропускать разделы «нет данных» — писать `[гипотеза]` с обоснованием
- Писать расчёты без чисел
- Копировать без адаптации расчёты из TASK3 — доменный анализ должен добавлять новое
