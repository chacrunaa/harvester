**Как писать:**

## Раздел 2 — ARPU (средняя выручка на заказ)

**Что это:** Сколько в среднем зарабатывает бизнес с каждого заказа до вычета постоянных расходов.

**Как считать — показывай каждый шаг для Base-сценария:**

```
Шаг 1: Базовая цена юнита = [X <currency> из data/info/]

Шаг 2: Upsell выручка
  = attach-rate [из data/info/] × цена upsell [из data/info/]
  = [attach%] × [upsell <currency>] = [W <currency>]

Шаг 3: Gross Revenue/Order
  = базовая цена + upsell выручка
  = [X] + [W] = [X+W <currency>]

Шаг 4: Комиссия платёжной системы
  = Gross Revenue × комиссия [%] `[гипотеза]`
  = [X+W] × [%] = [C <currency>]

Шаг 5: Net Revenue/Order
  = Gross Revenue − комиссия
  = [X+W] − [C] = [N <currency>]
```

**Затем посчитай для всех трёх сценариев:**

## Раздел 6 — LTV (Lifetime Value)

**Что это:** Сколько в среднем приносит один пользователь за всё время. Для бизнес-моделей без подписки — особенно важный показатель.

**Метод 1 — Простой (по числу покупок):**

Из `data/info/` или логики продукта — оцени среднее число покупок за 12 мес:

```
Avg purchases/user (12 мес) = 1 + retention% × [коэффициент]
LTV (простой) = Net Revenue/Order × avg purchases
LTV = [Net Revenue] × [avg purchases] = [итого <currency>] (Base)
```

## Что НЕ делать

- Не писать «ARPU ≈ X <currency>» без расчёта — показывать каждый шаг
- Не использовать только один сценарий
- Не пропускать break-even со стресс-сценарием по ФОТ
