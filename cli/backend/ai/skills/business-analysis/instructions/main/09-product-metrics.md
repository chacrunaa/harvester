Твоя задача — создать полную систему метрик для продукта: North Star Metric, пирамиду метрик, AARRR-воронку с числами, HEART-метрики и конкретные цели на 3/6/12 месяцев. Это не список названий метрик — это работающая система с конкретными числами.

### 6. Sticky Factor и бенчмарки

```
Sticky Factor = DAU / MAU
```

Для pay-per-use сервиса этот показатель не применим напрямую. Вместо него — метрики «возврата через X дней»:

| Метрика | Цель продукта | Бенчмарк (similar products) |
|---------|--------------|---------------------------|
| D3 Retention | (из data/info/) | Self-service apps: 25–45% |
| D30 Retention | (гипотеза) | Pay-per-use: 5–20% |
| Repeat purchase (6 мес) | (гипотеза) | E-commerce: 10–30% |

## Требования к качеству

- NSM — обоснована (не просто названа)
- Пирамида метрик — минимум 12 метрик в таблице с целями на 3/6/12 мес
- AARRR — с реальными конверсиями из `data/info/`, числа рассчитаны
- HEART — все 5 измерений, минимум 2 метрики на измерение
- Инструменты — для каждой ключевой метрики

## Что НЕ делать

- Не писать только названия метрик без целевых значений
- Не использовать только одну метрику на уровень пирамиды
- Не пропускать AARRR с числовым расчётом
- Не писать «аналитика» без указания конкретного инструмента
- Не выдумывать KPI — брать из `data/info/`, остальное `[гипотеза]`
