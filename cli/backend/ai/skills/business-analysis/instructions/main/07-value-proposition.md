## Требования к качеству

- VP Canvas — для обоих приоритетных ICP полностью
- В каждом блоке VP Canvas — минимум 5 пунктов
- УТП — одно короткое (≤12 слов) + одно расширенное (3–4 предложения)
- Ключевые сообщения — для минимум 5 каналов с конкретными примерами текста
- Fit-оценка — есть для обоих сегментов

## Что НЕ делать

- Не ограничиваться 2–3 пунктами в блоках VP Canvas
- Не писать УТП без конкретных цифр («быстро», «дёшево» — не УТП)
- Не дублировать одни и те же пункты для разных сегментов — сегменты разные
- Не забывать про anti-positioning — важно понимать, от чего отстраиваемся
- Не выдумывать данные — все ценности, боли, выгоды должны следовать из `data/output/02-target-audience/`
