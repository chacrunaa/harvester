## Разделы документа

### 1. Методология расчёта

Описание обоих методов (3–4 предложения каждый):
- **Top-down:** берём общий объём рынка → сужаем по сегментам → оцениваем долю
- **Bottom-up:** от единицы продажи → количество покупателей → SOM

Источники данных: официальная статистика, отраслевые исследования, `[гипотеза]` с обоснованием.

### 2. TAM — метод Top-down (таблица + расчёт)

Расчёт шагами, каждый с числами:

```
Шаг 1: Общая целевая аудитория в год = X чел. [источник]
Шаг 2: Доля нуждающихся в продукте = Y% [гипотеза]
        → Y% × X = N чел./год
Шаг 3: Доля готовых к digital-сервису = Z% [гипотеза]
TAM = Z% × N × [средний чек из data/info/] = X <currency>/год
```

| Параметр | Значение | Источник |
|---------|---------|---------|
| Размер ЦА в год | (оценка) | (статистика/гипотеза) |
| Доля нуждающихся | X% `[гипотеза]` | Обоснование |
| Потенциальный TAM (кол-во) | N чел. | Расчёт |
| Средний чек | (из data/info/) | Данные клиента |
| **TAM в деньгах** | **X <currency>/год** | Расчёт |

### 3. SAM — фильтры от TAM

| Фильтр | Описание | Доля от TAM | Обоснование |
|--------|---------|------------|-------------|
| [Фильтр по географии] | (из данных продукта) | X% | (обоснование) |
| [Фильтр по сегменту] | | X% | |

**SAM = TAM × фильтр1 × фильтр2 = X <currency>/год** (расчёт явно)

### 4. SOM — метод Bottom-up

Воронка с реальными конверсиями из `data/info/`:

```
Посетители/мес → ×CR_visit→signup → Регистрации → ×CR_signup→payment → Заказы
(из data/info/)                     (рассчитать)                        (рассчитать)
```
