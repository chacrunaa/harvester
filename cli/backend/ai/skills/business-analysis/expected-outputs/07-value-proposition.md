### 3. Уникальное торговое предложение (УТП)

**Короткое УТП** (≤12 слов, для хэдлайна):
> «[Конкретная выгода] — [преимущество над конкурентом]»

Пример структуры (не копировать):
> «Переезд под ключ за 15 минут — без агентов и переплат»

**Расширенное УТП** (3–4 предложения):
> [Ценностное предложение для обоих ICP: что получают, за что платят, чем отличается от альтернатив]

**Проверка УТП:**

| Критерий | Соответствует? | Комментарий |
|---------|:-------------:|-------------|
| Конкретность (есть числа или факты) | Да / Нет | |
| Уникальность (конкуренты так не говорят) | Да / Нет | |
| Значимость для ЦА | Да / Нет | |
| Доверие (проверяемо) | Да / Нет | |

### 5. Positioning Statement (формула Geoffrey Moore)

```
Для: [целевой сегмент из data/info/]
Кто: [описание потребности]
[Название продукта]: [категория]
Который: [ключевое преимущество с данными]
В отличие от: [главный конкурентный вариант из 03-competitive-analysis/]
Наш продукт: [принципиальное отличие]
```

**Место на рынке:** [Продукт] занимает нишу «[описать]» — между [конкурент A] и [конкурент B].

**Карта восприятия (текстовая):** Ось 1 × Ось 2, где находится каждый игрок из конкурентного анализа.
