# Expected Outputs

Reusable output contracts for the business-analysis workflow.

Each file describes the expected result for one analysis package section:

- required output files;
- required sections;
- minimum completeness criteria;
- quality checklist.

These are not project outputs. They are reusable contracts for future projects.

## Files

- `00-analytics.md` - final analytical conclusion.
- `01-product-brief.md` - product brief.
- `02-target-audience.md` - target audience.
- `03-competitive-analysis.md` - competitive analysis.
- `04-bft.md` - business-functional requirements.
- `05-market-size.md` - market sizing.
- `06-business-model.md` - business model.
- `07-value-proposition.md` - value proposition.
- `08-unit-economics.md` - unit economics.
- `09-product-metrics.md` - product metrics.
- `10-financial-model.md` - financial model.
- `11-mvp-definition.md` - MVP definition.
- `12-custdev-plan.md` - CustDev plan.
- `13-market-insights.md` - market insights.
- `14-python-pipeline.md` - analytics scripts.
- `15-domains.md` - domain-specific analysis.
