### 4. Матрица решений (заполняется после 20 интервью)

| Гипотеза | Подтверждена (% из выборки) | Решение если НЕ подтверждена |
|---------|:--------------------------:|------------------------------|
| H1 (боль острая) | [%] | <50% → пересмотреть проблему |
| H2 (цена нормальная) | [%] | <40% → скорректировать цену |
| H3 (upsell нужен) | [%] | <20% → пересмотреть upsell |

**GO/PIVOT:**
- ≥4 из 6 подтверждены → GO
- 2–3 подтверждены → ITERATE
- <2 подтверждены → PIVOT

## Содержание скриптов интервью (12-custdev-plan-script-icp1.md и script-icp2.md)

Каждый скрипт содержит 4 блока, всего 18–20 вопросов:

**Блок 1 — Контекст и прошлый опыт (5 вопросов, 10 мин)**
| # | Вопрос | Цель | Follow-up |
|---|--------|------|-----------|
| 1 | Расскажите о последнем опыте [ключевое действие]... | Стартовая точка | «А что было до этого?» |
| 2 | Сколько времени ушло на весь процесс? | Измерить боль «время» | «Из них на поиск информации?» |
| ... | | | |

**Блок 2 — Боли и мотивации (5 вопросов, 10 мин)**
| # | Вопрос | Цель | Follow-up |
|---|--------|------|-----------|
| 6 | Что было самым неприятным? | Топ-боли | «Это случалось раньше?» |
| ... | | | |

**Блок 3 — Тест концепции (5 вопросов, 10 мин, БЕЗ показа продукта)**
| # | Вопрос | Цель | Follow-up |
|---|--------|------|-----------|
| 11 | Если бы существовал сервис [концепция]... | Проверить концепцию | «При каких условиях — да?» |
| 12 | Сколько готовы платить? | Ценообразование | «А если бы покрывал больше?» |
| 14 | Если бы была опция «[upsell из data/info/] за +[цена]» — добавили бы? | Тест upsell | «В каких случаях?» |
| ... | | | |

**Блок 4 — Закрывающие вопросы (3 вопроса, 5 мин)**
| # | Вопрос | Цель |
|---|--------|------|
| 16 | Что хотели бы, чтобы сервис делал лучше всего? | Желания |
| 17 | Есть ли знакомые с той же проблемой? | Рекрутинг |
| 18 | Хотели бы попробовать первым? | Тест интереса |

## Минимальные требования

- [ ] Суммарный объём ≥200 строк markdown (все файлы)
- [ ] Скринер ≥5 вопросов, отсекает неподходящих
- [ ] Скрипт ICP-1: ≥18 вопросов с целью и follow-up
- [ ] Скрипт ICP-2: отдельный, адаптированный (не копипаст ICP-1)
- [ ] Таблица гипотез ≥7 с пороговыми значениями
- [ ] Шаблон записи результатов заполнен (любой может использовать)
- [ ] Матрица решений GO/PIVOT заполнена
