# 15-domains — Доменный анализ

Эта директория содержит дополнительные аналитические документы, специфичные для типа бизнеса. Генерируется в **TASK4**.

## Структура

```
15-domains/
  marketplace/          ← Двусторонние платформы (GMV, take rate, ликвидность)
  ecommerce/            ← Интернет-магазины (SKU, логистика, сезонность)
  b2b-saas/             ← SaaS для бизнеса (ARR, NRR, sales funnel)
  mobile-app/           ← Мобильные приложения (DAU/MAU, ASO, ROAS)
```

## Когда какой домен применять

| Домен | Признаки | Ключевые вопросы |
|-------|---------|----------------|
| **marketplace** | Две стороны (поставщики + покупатели), take rate | Как решить холодный старт? Какой take rate? |
| **ecommerce** | Продажа товаров, доставка, SKU | Какова оборачиваемость? Где теряем на возвратах? |
| **b2b-saas** | Клиенты — компании, ARR, длинный цикл продаж | NRR > 100%? Payback period < 18 мес? |
| **mobile-app** | Основной канал — мобайл, DAU-центрично | ROAS > 2x? D7 retention выше бенчмарка? |
