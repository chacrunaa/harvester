# history/briefs

Legacy/aggregate зона.

Рабочие brief конкретной задачи теперь хранятся рядом с задачей:

```text
history/briefs/<role>/
```

Рабочие role-директории: `analyst`, `architect`, `tester`, `reviewer`.

В эту директорию можно складывать только сводные cross-task отчёты, если они понадобятся позже.
