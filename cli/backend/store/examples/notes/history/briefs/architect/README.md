# history/briefs/architect

Brief-ы архитектора для возврата задачи в анализ.

Формат имени:

```text
<TASK_ID>.analysis-adjustment-brief.md
```

Brief создаётся, когда архитектор не может безопасно дополнить handoff сам и
возвращает задачу в `analysis`. В нём должны быть конкретные блокеры,
документы/код для повторного анализа и ожидаемый результат до повторной
передачи в `architecture`.
