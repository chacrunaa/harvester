# history/reports/architect

Рабочие отчёты архитектора по задачам.

Формат имени:

```text
<TASK_ID>.architecture-report.md
```

Отчёт фиксирует архитектурный итог стадии `architecture`: что проверено,
что дополнено в analyst handoff, какие ограничения обязательны для разработки,
какие риски остаются и можно ли передавать задачу в `2-develop`.
